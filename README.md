# 📘 Question 05 – Calculator Java Program #
This repository contains the solution for Question 5 of the lab exercise.
The task is to implement a Java class named Calculator with three methods and use them to evaluate two mathematical expressions.

# ✅ Requirements #
Create a class called Calculator and implement the following methods:
🔹 add(int a, int b)
Adds two integers and returns the result.
🔹 multiply(int a, int b)
Multiplies two integers and returns the result.
🔹 square(int a)
Returns the square of an integer (multiply the number by itself).

# 📌 Calculations Performed in main() Method #
Use the above methods to evaluate:

# (3 × 4 + 5 × 7)² # 
   
# (4 + 7)² + (8 + 3)² #

# 🖥️ Output #
# (3 × 4 + 5 × 7)² # = 2209 # 

# (4+7)² + (8+3)² = 242 #
